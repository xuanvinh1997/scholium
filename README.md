# Scholium site

Static site for GitHub Pages: home, support, privacy policy, terms. English and Vietnamese on one page (EN/VI switch).
No build tools, no dependencies, no tracking, no cookies. All links are relative, so it works under a repo path
(`user.github.io/<repo>/`) and later under your own domain without changes.

## Edit and rebuild

Pages are generated by one script. The privacy policy is generated from `docs/privacy.md`, which stays the source of truth.

```bash
/usr/bin/python3 scholium-site/tools/build.py
cd scholium-site && /usr/bin/python3 -m http.server 8765   # preview at http://localhost:8765/
```

Owner settings are at the top of `tools/build.py`:

| Setting | What to do |
|---|---|
| `EFFECTIVE` | Set to the day you publish the policy. |
| `CONTACT_EMAIL` | Fill in once a private support address exists. It then appears on Support and Privacy. Empty means no email is shown. |
| `ISSUES_URL` | Public bug tracker used on Support. Currently the `notebook-plus-privacy` repo. |
| `APP_STORE_URL` | Fill in when the app is live. The "Coming soon" button becomes "Download on the App Store". |

## URLs the app and App Store Connect need

The app opens the privacy policy at `https://xuanvinh1997.github.io/scholium/privacy/` (`NotebookPlus/App/LegalLinks.swift`).
App Store Connect currently has `https://xuanvinh1997.github.io/notebook-plus-privacy/`. **They must match.** Either serve this
site from the `ai-research` repo (the URL then matches the shipped build), or set the App Store Connect URL to wherever you host it
and change `LegalLinks.privacyPolicy` in the next build.

| Page | Path |
|---|---|
| Home | `/` |
| Support (use as the App Store **Support URL**) | `/support/` |
| Privacy policy (use as the **Privacy Policy URL**) | `/privacy/` |
| Terms | `/terms/` |

## Publish

1. Copy the contents of `scholium-site/` (not the folder itself) to the root of the Pages branch of the repo, or point Pages at this folder.
2. GitHub repo → Settings → Pages → deploy from the branch.
3. Custom domain later: add a `CNAME` file containing the domain, set the DNS records GitHub lists, tick "Enforce HTTPS". Nothing else changes.

`404.html` links to `/`, which is right on a custom domain. On a project path (`user.github.io/<repo>/`) it points to the user root instead.

## Before going public

- Replace the effective date and fill in `CONTACT_EMAIL` (the privacy policy itself says a privately handled contact channel must exist before release).
- The Pro paragraphs (price, "works with Family Sharing", lifetime updates) must match App Store Connect: Family Sharing turned on for the IAP, price $29.99.
- `docs/privacy.md` still says "Notebook Plus"; the site renders it as "Scholium". Update the source when convenient.
- Terms are plain language plus Apple's standard EULA. Have them reviewed if you want legal certainty.
